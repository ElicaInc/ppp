# Poops

Poops は、カメラ映像に反応して 3D のうんこオブジェクトを画面上に飛ばして遊ぶ、インタラクティブ Web 体験ライブラリです。

手・顔・姿勢のランドマークを利用し、指先を動かす、口を開ける、または画面上のオブジェクトに触れるといった動きで、カラフルな 3D オブジェクトを出現・操作できます。

## 特長

- Three.js で描画する 3D うんこオブジェクト
- `object_poop.glb` の 3D モデルを読み込み、色・サイズ・回転を変えながら表示
- 指先から 3D オブジェクトを出すハンドインタラクション
- 口を開けると 3D オブジェクトを放出するフェイスインタラクション
- 指先との衝突を扱う物理演出
- オブジェクトのサイズ、落下速度、密度を調整できるコントロール
- PC、スマートフォン、タブレットのカメラに対応

## 使い方

`index.html` を、カメラへのアクセスを許可できるローカル Web サーバー上で開いてください。起動後にカメラの使用を許可すると、画面内のタブから各エフェクトを選べます。

## 主なファイル

- `index.html` — メインのインタラクティブ体験と 3D 描画処理
- `object_poop.glb` — 表示に使用する 3D オブジェクトモデル
- `object_poop.ply` — 3D モデルの PLY 形式データ
- `glassBall.js` — 既存のガラス／屈折風表現に関する描画処理
- `0.html`、`1.html`、`2.html` — 個別の実験ページ
